## Module Map
### domain/source/MusicSource.kt [service — interface]
- **Does**: abstraction over remote catalog + audio. songId = YouTube videoId.
- **Impl**: `data/source/youtube/NewPipeMusicSource`

### data/source/youtube/NewPipeMusicSource.kt [repo]
- **Does**: YouTube catalog via NewPipeExtractor. Home = genre/trending searches; search MUSIC_SONGS/ALBUMS/ARTISTS; relatedTo (queue); resolveStream → progressive audio URL.
- **Depends on**: NewPipe `ServiceList.YouTube`, `StreamInfo`; `NewPipeDownloaderImpl` (init'd in app)

### data/repository/MusicRepositoryImpl.kt [repo]
- **Does**: wraps MusicSource on `Dispatchers.IO`; TTL cache for resolved streams; static browse tiles.

### data/repository/LibraryRepositoryImpl.kt [repo]
- **Does**: liked songs + user playlists via Room; reactive `Flow`s.
- **Depends on**: `data/local/dao` (SongDao, LikeDao, PlaylistDao)

### playback/MediaControllerManager.kt [service]
- **Does**: builds `MediaController`, exposes `StateFlow<PlayerState>`, transport commands, 500ms position ticker.
- **Exports**: `state`, `playSongs/togglePlayPause/next/previous/seekTo/toggleShuffle/cycleRepeat/...`

### playback/PlaybackService.kt [service]
- **Does**: `ExoPlayer` w/ `ResolvingDataSource.Factory(DefaultHttpDataSource, StreamUrlResolver)`; UA matched to downloader; one `MediaSession`.

### ui/player/PlayerViewModel.kt [service — shared VM]

## Key Facts / Gotchas
- `MusicSource` is **NewPipe-only** today; InnerTube hybrid Home is planned but NOT built.
- Stream URLs expire ~6h + IP-bound → resolved per-track at load via `StreamUrlResolver` (never cached long).
- Media3 unstable APIs opted-in with `@UnstableApi` (PlaybackService, StreamUrlResolver).
- Build: needs `JAVA_HOME`=Android Studio JBR; `android.disallowKotlinSourceSets=false` (AGP9 built-in Kotlin + KSP).
- Not Play-shippable (YouTube ToS + GPLv3 from NewPipeExtractor).
